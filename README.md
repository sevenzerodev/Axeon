## ✨ About

Axeon is a modern Java-based Minecraft: Pocket Edition server API focused on performance, flexibility, and clean architecture.

Built with inspiration from Nukkit and PocketMine-MP, Axeon provides developers with a solid foundation for creating multiplayer servers, plugins, and custom gameplay systems.

## 📦 Installation

### Requirements

| Requirement | Version |
| :-- | :-- |
| Java | 8+ |
| Maven | Latest |
| Git | Latest |

---

### Clone Repository

```bash
git clone https://github.com/sevenzerodev/Axeon.git
cd Axeon
```

---

### Build Project

```bash
mvn clean package
```

Compiled jars will appear inside:

```text
target/
```

---

### Start Server

```bash
java -jar Axeon.jar
```
